# Fonts, page chooser, optional capture and moving poses — 00.08

Triangle opens a ten-row settings menu. The new Police row selects System, DejaVu Serif, DejaVu Sans or DejaVu Sans Mono. The three TrueType files and original upstream licence are bundled; only the selected custom font is loaded. Measurement, drawing, apostrophe spacing, justification and line-height calculations all use that font. Switching font repaginates around the current text anchor, with a fallback to the previous font on failure. Font selection also applies consistently to menu labels.

Capture sur signet is disabled by default. VRS1 settings migrate with all previous preferences retained, system font and captures disabled. VRS2 persists both new fields; enabling capture restores the 00.07 PNG behavior, while disabling it leaves existing images untouched.

L + R opens a whole-book page chooser. The trigger handler waits up to 90 ms for a chord before emitting a single-trigger turn, emits the chord once and suppresses stray turns until both triggers are released. Left/right changes the target by one page, up/down by ten; touch/drag the slider for larger jumps. Cross confirms, Circle/Triangle cancels, and L + R can close the picker. All chapters are counted with the current layout on first use, retaining only counts, current chapter and preview; cached counts reset on layout/font changes. Initial indexing can take time on long EPUBs and is synchronous. Target chapter loading commits only after success. Pages are logical pages of the entire book, not the chapter-local footer count. A spread begins at the selected page. Explicit pinned resume bookmarks remain pinned when jumping elsewhere.

The light library now draws three faint mascot situations from one alpha atlas, translated slowly with independent phases. Capturing the shelf for the opening animation freezes the same pose positions. See [asset and exact generation prompt](../assets/branding/MASCOT_POSES.md). The atlas was generated with built-in imagegen and the supplied logo reference; original branding files remain intact. DejaVu 2.37 source: [upstream release](https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37), licence in `assets/fonts/LICENSE`.

Portable regressions cover trigger chords, release suppression, taps/repeats, whole-book bounds and cross-chapter jumps, count invalidation after reflow, VRS1 migration and VRS2 persistence. Hardware checks: French glyphs and justified lines in each font, page indexing latency, picker/slider controls and cancellation, disabled-by-default screenshots, restored preferences and calm pose movement/frame pacing.
