# Second device review — 00.04

The user reported persistent save failures, wide apostrophe spacing and successful page swipes only about once in fifteen attempts. Previous host/native build success did not establish resolution on hardware.

- **Storage:** prior SELF packaging used VitaSDK's restricted default. 00.04 uses `UNSAFE`, the official option for extended homebrew permissions, while retaining the same title ID and data paths. Direct Vita mkdir/getstat creates/verifies parent directories before each write. Native errors now show the operation, hexadecimal result and file/directory basename instead of a generic warning. Partial writes, backup replacement and VR3 anchors remain supported. The application can still discover/read books when storage initialization fails. This packaging correction is a plausible explanation for the persistent device error; device confirmation remains necessary. VitaShell may request extended homebrew permission when installing this package.
- **Touch:** a swipe now starts anywhere on the page, not only inside a 96 px edge zone. Direction is decided after 24 px horizontal travel; dominant vertical motion is rejected. Release accepts 22% travel or a recent 0.45 page-width/s flick after 6% travel. Contact cancellation rules remain. Regressions exercise forty center-start forward/backward gestures, vertical rejection and contact tracking.
- **Typography:** Unicode apostrophe variants normalize to a Latin apostrophe for rendering. Its horizontal advance is capped relative to a lowercase Latin letter, using exactly the same calculation for pagination/measurement and drawing. A mocked 40 px punctuation advance proves the following word starts after 4 px instead. EPUB whitespace/elision normalization remains active; this change specifically addresses font fallback spacing.
- **Opening:** after Cross or tapping the selected spine, the selected book grows out of its shelf, opens its matching cover and reveals the prepared reader scene over 650 ms. Two reused render targets hold the shelf and reader snapshots. Inputs are held during opening; Circle cancels back to the shelf. Parsing happens before animation so an invalid book leaves the library usable. Surface-allocation failure opens the reader directly.

Acceptance on Vita: verify repeated automatic saves and a pulled bookmark across restart; if an error persists, report its displayed `open/write/mkdir/rename` hexadecimal code. Try short and long center-start swipes in both directions. Inspect `L’homme` and `d’abord`, line wrapping and the shelf-opening animation. Build results are recorded separately in `VALIDATION.md`.
