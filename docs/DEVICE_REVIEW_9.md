# Library folder options — 00.12

Triangle in the library opens options: refresh, choose the books folder, or restore the default. The directory browser starts in the configured folder, displays sorted subdirectories and offers Select current folder, Parent and Other storage. The mount list includes ux0, uma0, imc0, xmc0, ur0, gro0 and grw0; unavailable mounts report an error without changing the active library. Navigation supports D-pad/stick, Cross, Circle, L/R paging and select-then-open touch.

The configured path is normalized and saved atomically in `ux0:/data/VitaReader/library.cfg`, separately from reading settings. Missing/invalid configuration uses `ux0:/data/VitaReader/books`. A selection first scans the proposed directory and saves its configuration, then replaces the active library. Failed scans or saves retain the previous active directory and books. Existing custom directories are scanned without creating or moving files. Discovery is non-recursive and includes EPUB and PDF. The path appears on the shelf and in the empty-library message.

Portable tests cover normalization, root/parent paths, spaces, malformed configuration, round-trip persistence, backup reads, rejection without replacing a saved path, sorted folder enumeration, mixed EPUB/PDF discovery and unavailable folders. On hardware, choose folders on ux0 and uma0, test long paths and more than eight subdirectories, confirm empty directories, restart, disconnect a selected storage device and recover through options. Check default reset and return from a book. Positions remain keyed to each book's full path.
